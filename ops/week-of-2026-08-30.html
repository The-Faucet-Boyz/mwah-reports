⭐ Three things that changed the most this week
The biggest user-facing wins — visible improvements to how the platform feels and works.
📊

Command Center now scopes to a single market

The main dashboard charts can now be filtered to focus on one market at a time. A new "units sold" metric is also visible alongside the existing views, and the header band was resized to fit without crowding.

Dashboard
🌙

Dark mode is fully redesigned

The dark theme now uses a graphite canvas, an indigo accent, and a clearly separate button style for calls to action. Both light and dark modes now look intentional rather than one being an inversion of the other.

Theme
📋

Materials table groups by category and collapses

When allocating materials for a production run, the table now organizes items by group and can be collapsed section by section — much easier to navigate when planning a large batch. One-click overage was also removed to keep the workflow intentional.

Planning
🧾 Purchase orders and documents got a lot of attention
Several improvements to how POs and invoices are created, displayed, and downloaded.
📄

Proforma Invoice downloads are now available

You can now pull a blank or pre-filled Proforma Invoice directly from the ordering screen. The pre-filled version carries the current order details; the blank version is ready for manual completion.

PI
🗂️

New PO drafts now appear sorted by lane

Purchase order drafts are ordered by their delivery lane when they're created, and that ordering is now configurable. A tooltip issue that had been lingering was also resolved in the same pass.

PO
✅

PO quantity column now correctly totals units

The goods table on a vendor purchase order was summing the number of lines rather than the actual units ordered. It now shows the true quantity total, which matters when ordering across many SKUs.

PO Fix
🎨

PO and PI document quality tightened

Table layout, file naming conventions, and goods-row typography were all refined across the purchase order and proforma invoice document views.

Polish
🔌 Integrations and data feeds are more accurate
Incoming data now maps cleanly, and labels in the interface now match what they actually represent.
🔗

New CA product codes accepted and auto-mapped

Several new SKU codes from the CA distribution platform are now accepted and automatically aliased to the correct catalog entries. Orders using these codes no longer get flagged as unknown items.

CA Sync
🏷️

CA data feed labeled by its actual source

The CA market data feed is now labeled consistently by its real source throughout the interface, removing a confusing mismatch that made the sync status harder to read.

CA Sync
🧭 The planning flow and overall experience were refined
From the first loading screen to the last step of planning an order, small things add up.
⭕

Branded loading animation on every page

A loading ring now appears while the app initializes on page load, replacing a blank flash. Small detail, but it makes the experience feel more polished from the first moment.

UX
📑

Plan Order flow has market tabs, clearer gates, and better labels

You can now switch between markets directly within the Plan Order flow using market tabs. The gate between steps now reflects what's actually required to proceed. Component terms are standardized throughout.

Planning
📦

Cross-market components admitted at the commit step

Components sourced from another market can now be admitted directly at the commit step, rather than requiring a detour into a separate workflow.

Planning
☀️

Light-mode contrast improved across the board

A palette audit identified several areas where light-mode contrast fell short of the standard. All flagged spots have been corrected.

Accessibility
🐞 Fixes and small polish
Corrections to things that weren't working quite right.
🔍

Plan picker now shows components already on a line

Components already added to the current plan line were being silently hidden from the picker, making it look like they didn't exist. They're now visible and clearly labeled as already in use.

Planning
💬

Revenue captions condensed; tooltip figures no longer clip

The revenue label on the dashboard header is more concise. Money values in tooltips no longer get cut off at the edge. PO figures now have plain, accurate names rather than technical shorthand.

Fix
🛠️

Interface polish across filters, planning toolbar, and copy

Filter controls now match the height of adjacent fields. The materials allocation toolbar and its targets step were refined. Redundant instructional copy in the planning flow was trimmed.

Polish
🔧

PO lane policy wired correctly; three silent issues fixed

The lane policy for purchase orders was not being applied in the right places. Three degradations that had been silently producing wrong behavior were identified and corrected.

PO Fix
