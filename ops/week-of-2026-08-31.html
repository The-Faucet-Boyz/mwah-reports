⭐ Three things that changed how the week feels

📊

Command Center now shows results by market

The main dashboard charts can be scoped to a single market. Units sold appear alongside the other metrics, and the layout fits cleanly without overflow.

Dashboard
📋

Material allocation is grouped and collapsible

The allocate-materials step in a plan run now organizes ingredients by type, lets you collapse categories you've finished, and prevents accidental over-allocation in a single click.

Plan Run
🗂️

Plan Order flow has dedicated tabs per market

Each market's planning lives in its own tab. The gate into step 3 only triggers when there's actually something to review — no more stepping past an empty confirmation screen.
