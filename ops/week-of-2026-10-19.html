⭐ The biggest wins this week
The changes you'll feel most immediately.
🏭

Vendors now have a full workspace

The supplier page went from a simple list to a real working environment. Vendors can upload and update invoices, view purchase orders alongside their own documents, track shipments, and search or switch between a card board and a row list — all without leaving a single screen.

Vendor Portal
📋

Order Center now centers around individual POs

Each purchase order gets its own card. Clicking it filters the product table to that PO's items, side panels let you inspect details without losing your place, and the layout is tighter and more readable across the board.

Order Center
🔌 The vendor portal is a real workspace now
Everything a supplier needs to resolve an order is one screen.
📄

Upload and update invoices from a PO

Teams can upload an invoice directly from a purchase order card, or update one already on file. No need to navigate elsewhere — the action is right where the order is.

Invoices
👁️

View any invoice, however it arrived

Whether an invoice came in by email, manual upload, or an automated sync, the vendor page now surfaces a direct link to view it. Every invoice on file is reachable from one place.

Invoices
🚚

Shipment details in a single tap

A new details popover on the vendor board gives a quick read of shipment status. A button in the list lets you request a change right from where you're working, without opening a separate page.

Shipments
🔀

Board or List view, with search

The supplier page now has a Board/List toggle and a live search bar. Browse vendors in the layout that fits the task — switch at any time without losing your filters.

Supplier Page
✅

Done section keeps the right context

The Done section on the supplier page now stays on the vendor's page so teams can continue reviewing completed work without being bounced to a different view.

📊 Order Center got a cleaner, more interactive layout
Faster to scan, easier to dig into the details you care about.
🃏

One card, one purchase order

The Order Center now shows exactly one card per PO. Link related items with drag or a button, expand side panels for the full picture, and zeros now appear explicitly rather than as empty space.

Order Center
🔍

Click a PO to filter products

Selecting a purchase order in the Order Center now filters the Products table to that PO's items, with one row per line item and statuses shown as readable labels rather than icons alone.

Products

🏷️

MWAH wordmark in the application header

The top bar now displays the MWAH brand mark, styled to match whichever appearance you have selected. It fits naturally across all four theme modes.

🐞 A handful of Order Center fixes landed too
Rough edges smoothed out.
📦

Packaging status is accurate for partial orders

Orders that are only partly packaged now show the correct short count instead of an incorrect or missing value. The figures column is also better aligned with the totals row.

Fix
💬

Tooltips appear only where they add something

Hover pop-ups in the Order Center now appear only on elements where the extra context is genuinely useful. The rest of the interface is quieter as a result.

⚙️ Behind the scenes
  • Browser-level read caching (30 s) reduces redundant data fetches and speeds up page loads.
  • The invoices-awaiting dashboard card now runs a tighter query, cutting unnecessary reads.
  • Dependency upgrades across the platform, including the underlying database and cloud-function libraries.
  • New portable verification tooling to catch regressions faster in CI.
