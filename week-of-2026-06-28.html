⚙️ Behind the scenes
  • GitHub Actions deploy auth was fixed — post-merge deploys had been failing due to a WIF token handling issue. The fix wires in a proper short-lived access token and deploys are reliable again.
  • ShellHeal now catches unhandled async errors: unresolved promise rejections in the app shell are recovered gracefully, reducing blank-screen incidents on flaky connections.
  • Two stale-build recovery guards were added — one for the app shell on first load, one for the Inventory page — so a cached old build clears itself instead of leaving the page in a broken state.
  • MWAH product SKUs were re-stamped for WA compliance: BBA, MMA, and PPE SKUs now carry the correct WA format for regulatory alignment.
  • The Competitor Pricing menu crawler now handles age-gated store websites automatically, filling in a date of birth to get through — no more data gaps from stores that gate their menu behind a birthday prompt.
  • POSaBIT vendor API error handling and retry logic hardened — transient API failures now recover instead of silently leaving a store's inventory data stale.
  • A background health probe was added to portal email delivery — catches sendmail issues before they reach buyers.
  • VMI Ordering v1 shipped behind a feature flag — the end-to-end reorder flow is built and dark, ready to light up per account once QA is complete.
  • Nabis CA import pagination was fixed — stores on pages past the first were being dropped. The full dataset now imports cleanly.
  • Menu resolver now logs progress incrementally so a slow crawl job is observable as it runs, instead of appearing stuck.
  • Inventory manual refresh button now times out gracefully after a long POSaBIT sync, instead of hanging indefinitely.
  • Website dependency bumps: npm packages updated across the public site and CA import function.
