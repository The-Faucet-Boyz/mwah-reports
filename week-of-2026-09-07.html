⭐ Highlights
🗺️

The map got a full rebuild — plan routes, track visits, and see territory coverage at a glance

The Stores map is now a territory planning tool. Reps can switch between three views: Off (default clean slate), Visits (color-coded by how recently a store was seen), and Coverage (colored by the strength of the relationship). A Washington state boundary keeps you oriented, the filter panel works exactly like the list view so saved filters apply everywhere, and you can plot a driving route straight from the filtered results — waypoints auto-sorted into an efficient order with turn-by-turn ready to hand off to Maps.

Map + Territory
📊

Inventory numbers overhauled — 44 data issues corrected across Inventory, Insights, and Trends

A systematic audit found and fixed 44 individual data issues across the Inventory, Insights, and Trends dashboards — bad subtotals, miscounted segments, tooltip totals that didn't add up, and a Days Supply field that was reporting 99 when it couldn't be calculated instead of honestly saying "unknown." Every one of these is fixed and the numbers now tell the real story.

Inventory + Analytics
📍 Stores + territory
🔍

Filter row rebuilt around what reps actually ask

The filter bar on the Stores and Map pages was reorganized around the questions reps ask most. The most-used filters are front and center now, and the layout stays consistent between the list view and the map so switching between them doesn't mean re-learning the controls.

Stores
🏆

Contests now live under the Stores tab

Contest tracking moved into the Stores section alongside the map so it's easier to find in context. You no longer need to navigate to a separate area to check on active contests for stores you're looking at.

Stores
🎨

Map coverage view with color toggle and ring indicators

The Coverage view on the map now colors stores by the type of relationship (consignment, wholesale, etc.) with a toggle to switch between relationship mode and intensity mode. Larger stores show a ring around their pin so size differences are easier to read at a glance.

📋 Proposals + store detail
🔎

Store drill-down opens right inside a proposal

When reviewing a proposal, reps can now expand a store's detail panel inline without navigating away. The panel includes week-over-week deltas so you can see how the store's numbers shifted since the last proposal period — all without losing your place in the proposal list.

Proposals
📧

Read full email threads right in the activity feed

Activity rows that reference an email can now be expanded to show the full message body inline. No more switching to a separate view to see what was actually said.

Proposals
🏷️

Contact tags visible in the People tab

Any tags you've added to a store contact now show up directly in the store's People tab, so reps don't need to open the full contact record to see at-a-glance labels like "decision maker" or "does reorders."

Store detail
📦 Inventory + analytics
⚡

Store Triage opens on the most urgent stores first

When you open the Store Triage view in Inventory, it now defaults to sorting by shortest runway — stores that are closest to running out of stock come first. The most pressing situations are at the top without any manual sorting needed.

Inventory
📉

Samples metrics unified across CRM and reporting

The "Samples Given Out" number was being calculated differently in the CRM dashboard vs. the analytics reports, causing totals that didn't match. There's now a single definition that both surfaces share, so the numbers are consistent everywhere you look.

Analytics
🔕

4 high-volume notification types are now opt-in

Four notification types that were firing too frequently for most reps — including certain order-edit alerts — are now off by default. Anyone who wants them can turn them back on in their notification settings. The default inbox is quieter for everyone else.

Notifications
💲

Discounts dashboard simplified, pricing tabs cleaned up

The Discounts dashboards and pricing tabs were carrying redundant sections that added noise without adding clarity. Both were streamlined — same information, fewer clicks to get to it.

Product carousel on the homepage loops without stopping

The product showcase on gimmemwah.com now loops continuously — once it reaches the last product it wraps back around automatically instead of stopping at the end. A smoother experience for visitors browsing the lineup.

⚙️ Behind the scenes
  • Contact notes migrated to a proper subcollection — faster reads and a cleaner data model for large stores with many contacts.
  • Store notes and fulfillment notes exposed in the automation layer — agent tools can now read and update notes without a workaround.
  • Map CSS injection fix — a timing bug was causing the map to load unstyled on some navigations; a spinner now holds the map until tiles are ready.
  • Rep identity anchored to user ID in analytics — display-name snapshots were causing reps to appear as separate entities after a name change.
  • Alert noise reduced — order edits that only touch an invoice number no longer trigger notifications to the ops team.
  • Semantic routing eval questions pinned — each question now has a single canonical answer path, preventing drift across model updates.
  • BigQuery samples view made NULL-safe — blank store IDs were producing phantom rows in aggregate reports.
  • CRM audit gaps closed and several obsolete code paths removed.
  • Sentry alert-rule sync ported to the Workflows API; the old approach was deprecated.
  • Dependency maintenance across CRM and website: svix, pdfkit, resend, BigQuery client, googleapis, qs, fast-uri, and others updated.
