Stores

⭐ Highlights
🏗️

Store pages now show real WA state data — LCB licensing activity and CCRS wholesale purchases, right in the CRM

The at-register data card in Store Detail has been replaced with a live state data card sourced directly from LCB filings and CCRS. Reps can now see each retailer's wholesale purchase history and licensing activity without leaving the store view — no more switching between systems to verify what a store is actually buying.

Store Detail
📐

Dashboard columns are now evenly spaced, and the Chains directory got a proper data grid with retail and wholesale figures

The dashboard home screen now uses three equal-width lanes that align cleanly with the KPI row above. The Chains directory was also updated with explicit grid tracks, a Retail 2025 (LCB) column, and a clear dash where chain coverage is incomplete — replacing a layout that could shift or misalign on different screen sizes.

Dashboard
🏪 Store Detail
📊

Analytics in Store Detail now splits into Sales and Products sub-tabs

The Analytics panel in a store's detail view has been separated into two focused tabs: Sales (performance over time) and Products (what that store carries). Each tab loads only what it needs, making the view faster and less overwhelming.

Stores
🗂️

Store Detail actions and controls are cleaner and easier to scan

Less-used actions were consolidated and the Analytics cards were simplified. Delete controls are less prominent so the most important actions are easier to find — especially useful when quickly reviewing a store during a route.

Stores
🔀

Retail and Wholesale accounts for a chain can now be sorted together

When a chain has both Retail and Wholesale CRM accounts, they now sort together across the stores list so you can compare them side by side instead of hunting through a long list.

Stores
📋 Permits + alerts
🔔

Permit-refusal alerts now automatically tag the right ops team members

When a store's permit status creates a refusal condition, the Slack alert now directly tags Maddie, Hannah and Luu — so the right people are looped in immediately without anyone having to forward the message.

Alerts
🚫

Placing an order now surfaces any stores with a blocking permit status up front

Before you submit an order for a store whose permit status would block fulfillment, the CRM now lists those stores prominently so the issue can be addressed first. Portal standing is also stamped at this point, and the Monday digest was updated to reflect current permit states accurately.

Permits
📈 Insights + analytics
📁

The Chains directory now shows Retail 2025 and Wholesale columns

Directory rows now include dedicated LCB retail and wholesale purchase figures. If a chain's coverage is incomplete, a clear dash with an accessible explanation shows in that cell instead of leaving it blank or confusing.

Insights
🔍

Non-POSaBIT store insights now show the same last-order detail as POSaBIT stores

Stores not tracked through POSaBIT previously showed less context in the Insights view than POSaBIT-connected stores. That gap is closed — last order details now appear consistently regardless of how a store is tracked.

Insights
📝

The most recent proposal now appears on Insights, the store peek, and Store Detail

You no longer have to navigate into a store's order history to find the last proposal. It now surfaces inline wherever you're reviewing a store — on the Insights list, the store peek panel, and the full Store Detail page.

Orders
🔄 Reconciliation + operations
⚖️

The daily review alert now shows GrowFlow and CRM totals side by side

When an order appears in the morning reconciliation alert, you can now see both GrowFlow's reported total and the CRM's booked total in the same message. The matched CRM order is also named explicitly, so discrepancies are visible without opening either system.

Reconciliation
🗺️

Route planning tools on the map can now be hidden while you work

The route tools overlay can be toggled off when you need a clear view of the map while planning stops, then brought back with one click. The toggle now reads its state correctly from the page so it stays consistent across map interactions.
