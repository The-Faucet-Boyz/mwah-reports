⭐ Highlights
✉️

Every buyer-facing email was redesigned from scratch — cleaner, on-brand, and far fewer of them

The full suite of emails buyers receive from MWAH — order confirmations, change requests, and more — was rebuilt to match Kyle's new designs. The overhaul cut down on email noise (fewer sends, better timing), and the Order Confirmed email in particular now carries the polished look buyers expect. Bounce tracking was also added so the team gets an alert any time a delivery fails.

Buyer Communications
📊

Sales coaches now have a dedicated signals dashboard with review tools built in

A new Sales Signals surface is live in the CRM, giving sales coaches a consolidated view of rep performance, store activity trends, and the data they need to run account reviews. The Revenue card on the main dashboard was also updated with a clearer pace visualization and a Transferred segment key so every rep can see where they stand at a glance.

Sales Coaching
🌿 Flavors + Proposals
☕

Latte Lover is now live for reps via VMI-first rollout

The new Latte Lover flavor has launched to reps through the VMI program. Stores on VMI will see it surfaced in restock proposals automatically, with non-VMI stores to follow.

Flavors
🚀

Admins can now launch a new flavor without writing any code

The Admin panel has a new no-code flavor launch workflow. Admins set the launch details once, and the CRM automatically generates proposal menus for reps — no dev work needed for the next product drop.

Admin Tools
⚡

New flavor proposals now pre-fill based on a store's fastest flavor pace

When a rep opens a proposal for a new flavor, it now starts with a suggested quantity based on how quickly that store typically moves through similar products — less guesswork, faster order flow.

Proposals
🔄

Trade samples now show up correctly on POSaBIT reorder proposals

Trade sample units were missing from POSaBIT-generated reorder proposals. They're now included and properly separated from paid inventory so proposals reflect the full picture.

Proposals
📦 Orders + Fulfillment
✅

Confirming a VMI order no longer drops its line items

A bug caused a VMI order's lines to be replaced with a blank set when a manager confirmed it. Orders now correctly keep their original lines through the confirmation step.

Orders
💰

Editing a line on a paid order now reflects the correct stored total

When a rep edited a line on an order that had already been paid, the editor was showing a stale total. That's fixed — the editor now refreshes and shows the current value.

Orders
🧪

Sample units are now saved correctly when editing orders

A gap in how sample quantities were stored during line rewrites meant some sample orders were missing their unit counts. This is fixed going forward, and 26 affected orders were also repaired.

Orders
🏷️

Fulfillment tags are cleaner — price-group labels replace origin tags

Fulfillment rows now show a generic price-group tag rather than product-origin tags, and proposal suggestions are correctly labeled as "Proposals" throughout the flow.

Fulfillment
🎨 Design + Dashboard
🔘

CRM buttons are now consistent across every screen

All buttons in the CRM have been standardized to a unified component spec — the same size, shape, and hover behavior everywhere. Reps will notice a more polished, uniform feel throughout the app.

Design System
👤

Your Google profile photo now shows as your CRM avatar

The account avatar in the CRM shell now pulls from your Google account photo automatically, so reps see their own face rather than a generic initial bubble.

Shell
🌤️

Light mode got a cleaner white header and nav

The CRM's header and navigation bar in light mode are now a clean white with subtle hairline edges, replacing the earlier tinted look. The change makes the interface easier to read in bright environments.

Theming
📋

Credits and discounts tables now match the design system

The credits and discounts table views have been updated to follow the shared CRM design language — consistent spacing, typography, and the standard page header. The dashboard lane gap was also corrected.

Design System
✨

CRM finishing details: smoother interactions, better spacing, refined corners

A broad pass of polish landed across the CRM — hit areas are more generous, numeric counters use tabular figures so columns stay aligned, transitions have better easing, and nested card corners are tighter.

Polish
🔔 Alerts + Insights
🔕

Reps can now mute Slack alerts for specific stores

Stores that generate a lot of routine noise can now be muted on a per-store basis, so alerts stay meaningful. The permit digest was also updated to lead with stores that are actively ordering.

Alerts
📉

Inventory "Newly Connected" window corrected to 7 days

The Newly Connected store counter was showing a 14-day window when it should show 7 days. It's back to the correct range so the chip matches what reps expect.

Inventory
📝

Proposal email text field now shows a character counter instead of cutting off silently

Reps writing the text for a proposal email will now see a live character count as they type, rather than having their message silently truncated at 600 characters on send.

Inventory
